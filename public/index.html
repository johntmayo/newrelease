API Key Required

This app uses the TMDB API (free) to pull streaming and rental data.
To get started:

  1. Register at themoviedb.org
  2. Copy your API key from Settings → API
  3. Copy .env.example to .env and paste your key
  4. Restart the server

Data refreshes automatically every 6 hours once configured.
